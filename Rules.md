# LANDSYNC AI Engineering Constitution

1. Never fabricate government data, endpoints, credentials, or integrations.
2. Never claim legal title or ownership verification; show advisory uncertainty.
3. Never use Aadhaar as land identity or log/expose it.
4. Never expose or commit secrets; configure them through environment variables.
5. Never trust a user filename or bypass authorization.
6. Never automatically modify an authoritative record or delete immutable evidence.
7. Always preserve provenance, hashes, source hierarchy, model/provider/version, confidence, and audit trail.
8. Always route low-confidence or conflicting information to human review.
9. Always use migration-based schema changes and typed API contracts.
10. Keep state adapters isolated and do not hard-code one state’s vocabulary into the core domain.
11. Never couple UI directly to the database or put business rules in controllers.
12. Never mix synthetic fixtures with production connectors without a visible boundary.
13. Never silently normalize ambiguous land units; retain original unit and conversion evidence.
14. Always write and run a critical-path test with significant business logic.
15. Keep docs and backwards compatibility current; prefer explicit behavior over magical behavior.
